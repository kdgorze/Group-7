## 💻 Tech Stack  

### Frontend  
- **HTML/CSS/JavaScript (Vanilla)**  
- **Bulma CSS** for responsive styling and a clean UI.  

### Backend  
- **Node.js** with **Express.js** to handle routing and API endpoints.  

### Database  
- **Postgres SQL** for structured data storage and query management.  

## 🎯 Goals  
Our aim is to create a web app that allows users to:  
1. Manage pickleball tournaments.  
2. Track player rankings.  
3. Build a social community for pickleball enthusiasts.  

## 📈 Progress  
This repository will be updated weekly with new features, use cases, and documentation. 



### Use Case: Register for a Tournament  

**Actors:** User, System  

**Preconditions:**  
- The user is logged in.  
- The tournament exists.  

**Main Flow:**  
1. User selects a tournament from the list.  
2. User clicks "Register."  
3. System confirms the user's eligibility.  
4. System adds the user to the tournament's participants list.  

**Postconditions:**  
- The user is successfully registered for the tournament.  

**Exceptions:**  
- User is ineligible (e.g., rank requirements).  
- Tournament is full.
